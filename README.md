# Packet Tracer Labs

Laboratórios de redes que fiz no **Cisco Packet Tracer** durante os cursos da
Cisco Networking Academy (NetAcad). Cada pasta tem o arquivo `.pka`, um README
explicando o que foi feito e prints da topologia.

## Labs

| # | Lab | Conceitos | Dificuldade |
|---|-----|-----------|--------|
| 01 | [Roteador sem fio e um cliente](01-roteador-sem-fio) | DHCP, SSID, WPA2, gateway padrão, teste de conectividade | Fácil |
| 02 | [Conexão com um servidor da web](02-conectar-server-web) | Ping (ICMP), endereçamento IP, ARP, teste de conectividade, cliente-servidor HTTP | Fácil |

## Como abrir os arquivos

1. Instale o [Cisco Packet Tracer](https://www.netacad.com) (gratuito com conta NetAcad).
2. Baixe o arquivo `.pka` da pasta do lab.
3. Abra no Packet Tracer e siga as instruções da atividade

## Observação

Os laboratórios são de uso educacional. As senhas que aparecem nos arquivos
são apenas as do exercício e não são usadas em ambiente real.
